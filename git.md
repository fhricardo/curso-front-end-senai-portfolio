## Adicionar usuário

##### h5
###### h6
Para adicionar o seu usuário do GitHub ao VS Code, utilize os comandos abaixo:  
*Para verificar credenciais ativas*
```git config --global --list```  
*Para adicionar o nome de usuário*
```git config --global user.name "seu_nome_de_usuario_github"```
*Para adicionar o e-mail de usuário*
```git config --global user.email "seu_e-mail_do_github"```
